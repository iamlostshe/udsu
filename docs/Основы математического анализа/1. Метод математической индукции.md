Метод математической идукции (далее - ММИ) - это способ доказательства утверждений, зависящих от натурального аргумента.

---

Доказательство справедливости утверждения `S(n)`, для любого натурального `n`.

---

ММИ проводится в 3 этапа:

1. ==База индукции== - проверяется справедливость утверждения `S(n)`, при `n = n0` (`n0` - минимальное число последовательности, если нет доп условий `n0 = 1`).
2. ==Индукционное предположение== - предполагается справедливость утверждения `S(n)`, при любом натуральном `n = k`.
3. ==Индукционный переход== - доказывается справедливость утверждения `S(n)`, для числа `n = k + 1`, отталкиваясь от индукционного предположения (при некоторм натуральном `n = k`).
